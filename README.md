# Image Slider Library

A responsive image slider built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — semantic markup and sample image slides.
- `style.css` — responsive layout, viewport masking, controls, dots, and transform transitions.
- `slider.js` — modular `ImageSlider` class, dynamic dots, keyboard controls, and infinite boundary wrapping.
- `screenshots/` — illustrative application and source-code screenshots for the report.

## Run locally
1. Extract the ZIP archive.
2. Open `index.html` in a modern browser. An internet connection is required for the sample Unsplash images and Google Fonts.
3. Test Next, Previous, each dot, keyboard left/right arrows, and both boundary transitions.
4. If you want to avoid remote image dependencies, download images you have permission to use and update the `src` values in `index.html`.

## GitHub
Create a public repository named `image-slider-library`, then from this folder run:
```bash
git init
git add .
git commit -m "Build responsive image slider library"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/image-slider-library.git
git push -u origin main
```
Replace `YOUR-USERNAME` with your actual GitHub username. Confirm the repository is public before submitting its URL.
